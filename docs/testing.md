# Проверки и покрытие (FIN-238)

Каждый существующий тест отнесён к одному из трёх наборов средствами имён Go. Состав тестов сохранён; бизнес-сервисы в этой задаче не реализуются.

| Набор | Выбор Go | Тестов верхнего уровня | Что проверяется |
|---|---|---|---|
| unit | `^TestUnit` | 32 | Изолированные правила, преобразования, конфигурация, валидация, обработка ошибок |
| integration | `^TestIntegration` | 62 | PostgreSQL, миграции вверх/вниз/вверх, транзакции, схема, gRPC-сервер и клиенты, жизненный цикл, фоновые процессы |
| api | `^TestAPI` | 1 | `apitest.Start`: полная сборка, gRPC health, неподдерживаемый метод |

`TestAPIServiceStartsAndServes` обращается к полному приложению по gRPC с настоящим PostgreSQL. Тесты адаптера gRPC проверяют транспорт с тестовым сервисом, поэтому отнесены к integration. Чистые helpers `apitest.User`/`Caller`/`Reason` проверяются в unit. Тесты схемы вызывают PostgreSQL напрямую и не выдаются за API.

## Исходная точка 24.10.2026

| Набор | Statements | Выполнение тестов | Порог 80% |
|---|---|---|---|
| unit | 31.8% | Успех, PostgreSQL не нужен | Не выполнен |
| integration | 70.0% | Успех на PostgreSQL 18 | Не выполнен |
| api | 28.6% | Успех на PostgreSQL 18 | Не выполнен |
| combined | 86.4% | Информационное объединение | Отдельные наборы не заменяет |

Это исходный замер после классификации с `-race -count=1 -timeout=8m -coverpkg=./...`, а не подтверждение завершения FIN-238. Старые метрики строк сюда не переносились. Целевой 80% применяется к каждому набору; код и тестовая инфраструктура из знаменателя не исключались. Недостаток покрытия не скрывается и не заполняется искусственными тестами ради процентов.

`AccessPolicy` и `wire` ещё не реализуют бизнес-RPC сервиса. API-набор проверяет инфраструктуру, но не бизнес-сценарии. Их реализация остаётся в задачах разработки сервиса. До реализации и достаточных содержательных тестов обязательный CI gate остаётся красным; подготовленный PR — draft.

Команды, версия инструмента, одинаковый знаменатель, проверка пустого/неисполненного набора и артефакты описаны в [README](../README.md#покрытие-statements-по-трём-наборам-fin-238). Процент statements не доказывает полноту сценариев; проверка через тестовый gRPC-сервер не подтверждает работу с развёрнутыми соседними сервисами.
